# 🌐 Bhumika Gajbhiye — Portfolio Website

> **Live Site:** > bhumika-coder7.github.io/Portfolio/

A modern, fully responsive single-page portfolio website built with pure 
HTML, CSS, and JavaScript — no frameworks, no dependencies.

## ✨ Features

- Dark editorial theme with teal & amber accents
- Smooth scroll animations & reveal effects
- Custom animated cursor
- Interactive project filter (Power BI / Python / R / All)
- Inline Resume Viewer modal
- GitHub repositories showcase
- Fully responsive for mobile & desktop

## 🗂️ Sections

- **Hero** — Name, title, live status panel & impact stats
- **About** — Background, focus areas & availability
- **Skills** — 8 core skills with animated progress bars
- **Projects** — 6 featured projects with highlights & tech tags
- **GitHub Repos** — All 4 public repositories linked
- **Education** — M.Sc. Statistics & B.Sc. degrees
- **Certifications** — NPTEL, Udemy & Outskill credentials
- **Contact** — Email, LinkedIn & GitHub links

## 🛠️ Built With

HTML · CSS · Vanilla JavaScript · Google Fonts (Syne, DM Mono, Cormorant Garamond)
